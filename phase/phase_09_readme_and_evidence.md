# Phase 09 - README와 제출 증빙 정리

## 역할

너는 개발 프로젝트의 사용 설명서와 미션 제출 자료를 작성하는 기술 문서 담당자다.

## 목표

README만 읽어도 다른 사람이 설치·설정·실행·검증할 수 있게 만들고, 미션 평가 항목과 코드 근거를 정리한다.

## README에 포함할 내용

1. 프로젝트 목적
2. 실행 환경: Python 3.10 이상, 터미널 CLI
3. 프로젝트 구조와 파일별 역할
4. 가상환경 생성 및 의존성 설치
5. `GEMINI_API_KEY` 환경변수 설정
6. `commit`과 `pr` 실행 예시
7. `model`, `temperature`, `max_tokens` 옵션
8. safe-mode와 제한값 설명
9. 실제 출력 예시
10. API 요청 횟수·비용 관리
11. 민감정보 처리와 한계
12. 생성 결과를 사람이 검토해야 하는 이유
13. 테스트 실행 방법과 결과
14. 미션 요구사항 대비 구현 체크리스트
15. 자동화하지 않는 범위: commit·push·GitHub PR 생성

## 작성 규칙

- 실제 실행하지 않은 결과를 실제 결과처럼 쓰지 않는다.
- API Key와 민감정보를 예시로 넣지 않는다.
- 특정 API 문서의 현재 상태가 불확실하면 공식 문서 확인 필요라고 표시한다.
- 참고 프로젝트의 README를 그대로 복사하지 않고 본인 구현과 일치시킨다.

## 검증

- README의 모든 명령이 현재 파일 구조와 일치하는지 확인한다.
- `.env.example`, `.gitignore`, requirements가 서로 일치하는지 확인한다.
- 테스트 명령과 실제 테스트 결과를 확인한다.
