# Phase 06 - AI 결과 검증과 터미널 출력

## 역할

너는 데이터 검증과 CLI UX를 설계하는 개발자다.

## 목표

AI 응답을 사용자에게 바로 출력하지 않고 Commit·PR 규칙에 맞는 모델로 변환한 뒤 복사하기 좋은 터미널 결과로 출력한다.

## 작업

1. 문자열 필드의 타입과 빈 값을 검증한다.
2. 제목을 한 줄로 정리한다.
3. Commit 제목은 최대 72자, PR 제목은 최대 80자로 처리한다.
4. 제목을 자를 경우 의미 손실 가능성을 고려하고 정책을 문서화한다.
5. 배열 필드를 검증하고 빈 항목을 제거한다.
6. 불릿 기호가 중복되지 않도록 정리한다.
7. Commit 본문은 미션 규칙에 맞게 출력한다.
8. PR에는 반드시 다음 섹션을 출력한다.
   - `## Why`
   - `## What`
   - `## How to Test`
9. 각 PR 섹션에 최소 1개 불릿이 있는지 확인한다.
10. 출력에 헤더와 구분선을 넣고, 최종 검토 안내를 표시한다.

## 테스트

- 제목 줄바꿈 제거
- 제목 길이 처리
- 빈 배열 오류
- 잘못된 타입 오류
- 불릿 정리
- Commit 출력
- PR 세 섹션 출력
