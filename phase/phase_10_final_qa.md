# Phase 10 - 최종 미션 검증

## 역할

너는 제출 전 코드 리뷰와 미션 평가를 담당하는 시니어 리뷰어다.

## 목표

프로젝트가 6-2 미션의 공식 요구사항을 충족하는지 최종 점검하고, 필요한 수정만 수행한다.

## 최종 체크리스트

- [ ] Python 3.10 이상에서 실행된다.
- [ ] 웹 화면 없이 터미널 CLI로 실행된다.
- [ ] Git 저장소에서 status를 수집한다.
- [ ] Git diff를 수집한다.
- [ ] staged·unstaged 변경을 적절히 처리한다.
- [ ] 변경 사항이 없으면 API를 호출하지 않고 종료한다.
- [ ] API Key를 환경변수로만 관리한다.
- [ ] API 호출 실패 원인을 출력한다.
- [ ] model·temperature·max_tokens 옵션이 동작한다.
- [ ] Commit 제목과 선택적 본문을 출력한다.
- [ ] PR 제목과 Why·What·How to Test를 출력한다.
- [ ] 각 PR 섹션에 불릿이 있다.
- [ ] 제목 길이와 응답 형식을 검증한다.
- [ ] safe-mode 마스킹 또는 diff 제한이 동작한다.
- [ ] API 호출이 명령 1회당 1회 이내다.
- [ ] 실제 commit·push·PR 생성은 자동화하지 않는다.
- [ ] README에 설치·실행·설정·예시·주의사항이 있다.
- [ ] 테스트가 통과한다.
- [ ] 실제 API Key·개인정보·불필요한 대용량 파일이 저장소에 없다.

## 실행할 검증

```bash
python --version
python main.py --help
python -m unittest discover -s tests -v
python -m compileall -q .
```

가능하면 별도의 테스트 Git 저장소에서 다음을 수동 확인한다.

1. 파일 수정 후 `commit` 실행
2. 여러 파일 수정 후 `pr` 실행
3. 변경 사항 없는 상태에서 실행
4. API Key 없는 상태에서 실행
5. safe-mode 마스킹 확인
6. `--no-safe-mode` 경고 확인
7. 잘못된 옵션 입력 확인

## 최종 보고 형식

다음 내용을 보고한다.

- 구현 완료 기능
- 실행한 테스트와 결과
- 미션 요구사항 충족 여부
- 남은 제한 또는 수동 확인 사항
- 실제 제출 전에 사용자가 확인할 보안 항목

문제가 발견되면 먼저 원인을 설명하고, 범위를 벗어난 대규모 리팩터링은 하지 않는다.
